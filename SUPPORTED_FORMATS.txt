================================================================================
                         TECHNICAL DETAILS
================================================================================

WASM Libraries Used:
  • Photon WASM   - Image editing and filters (PNG, JPEG, BMP native support)
  • Magick WASM   - Format conversion (handles all formats)

Auto-Conversion Process:
  1. User uploads a non-Photon format (e.g., GIF, AVIF, WebP, TIFF)
  2. MagickService automatically converts to PNG for editing
  3. User can apply all editing features (filters, effects, adjustments)
  4. On download, user can export to compatible formats only

Format Compatibility Logic:
  Location: src/app/core/services/magick.service.ts
  Method:   getCompatibleOutputFormats(inputFormat: string): string[]

  Full Support Formats:
    ['png', 'jpg', 'jpeg', 'bmp', 'webp', 'tiff']
    → Returns: ['png', 'jpg', 'bmp', 'webp', 'tiff']

  Limited Support Formats:
    ['gif', 'avif', 'heic', 'heif', 'ico', 'svg']
    → Returns: ['png', 'jpg']

================================================================================
                         USAGE RECOMMENDATIONS
================================================================================

For Best Quality:
  • Upload PNG or JPEG for direct editing without conversion overhead
  • Export to PNG for lossless quality preservation
  • Export to JPEG for smaller file sizes (web-friendly)

For Modern Formats:
  • AVIF and HEIC can be uploaded but export as PNG or JPEG
  • WebP uploads work perfectly and can export to any format

For Animated Content:
  • GIF uploads supported but only first frame is edited
  • Export to PNG or JPEG (animation not preserved)

For Professional Work:
  • TIFF uploads supported (great for high-quality source images)
  • Can export back to TIFF or other professional formats
